# 🔗 URL Shortener Pro

A modern, feature-rich URL shortener built with React. Create custom short links, track clicks, and manage your URLs with style!

🌐 **Live Demo**: [https://willoid.github.io/url-shortener](https://willoid.github.io/url-shortener)

## ✨ Features

- **🎯 Custom Short IDs**: Create memorable short links
- **📊 Click Analytics**: Track how many times each link is clicked
- **🌓 Dark Mode**: Easy on the eyes with automatic theme switching
- **💾 Local Storage**: Your links persist between sessions
- **📱 QR Codes**: Generate QR codes for each shortened URL
- **🔍 Search**: Quickly find your links
- **📤 Export**: Download your URLs as JSON or CSV
- **📋 Copy to Clipboard**: One-click copying
- **📱 Responsive**: Works on all devices
